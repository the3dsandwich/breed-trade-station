# docs/research/

Source material and reference analysis. Describes things that already existed.

This folder is treated as **immutable reference**. Do not update files here to reflect new decisions — write a new file in `docs/design/` or `docs/architecture/` instead.

Examples of what belongs here:
- Analysis of the original Bunny game codebase
- Reference material on genetics or game design patterns
- Competitive analysis of similar games
