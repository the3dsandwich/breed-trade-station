# docs/architecture/

Technical decisions: stack choices, architecture decision records (ADRs), infra diagrams, API contracts.

If you are **deciding** something about how the system is built, it goes here.

Examples of what belongs here:
- Framework and language choices
- Client/server split decisions
- Database schema decisions
- Deployment architecture
- API design

Does not belong here: game mechanics (→ `docs/design/`), source analysis (→ `docs/research/`).
