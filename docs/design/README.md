# docs/design/

Game design decisions: mechanics, systems, economy, creature design.

If you are **deciding** something about how the game works, it goes here.

Examples of what belongs here:
- Genetics system design
- Breeding mechanic rules
- Economy and market system design
- Creature trait definitions
- Progression and order system design

Does not belong here: source analysis of prior work (→ `docs/research/`), technical stack decisions (→ `docs/architecture/`).
